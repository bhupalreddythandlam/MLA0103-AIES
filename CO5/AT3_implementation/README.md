# Automobile Fault Diagnostic System (Prolog)

A rule-based expert system written in Prolog to diagnose vehicle faults based on user-provided symptoms.

## Prerequisites
* You must have [SWI-Prolog](https://www.swi-prolog.org/download/stable) installed on your machine.

## How to Run

**Step 1: Open SWI-Prolog**
Launch the SWI-Prolog application to open the console (you will see the `?-` prompt).

**Step 2: Load the File**
Load the Prolog script into the environment using the `consult` command. Ensure you use forward slashes (`/`) in the file path and end the command with a period (`.`).
